# Python Learning Repository

This repository contains a collection of Python notebooks covering core programming concepts, data science workflows, machine learning, and computer vision. The notebooks are organized as hands-on practice exercises and demonstrations for learning by doing.

## Contents

The repo includes notebooks on:

- Python basics and data structures
- NumPy fundamentals
- Feature scaling and feature selection
- Logistic regression and regularization
- Model training with scikit-learn
- Image representation and processing
- Computer vision and digital image concepts
- Practical Python examples and documentation

## Notable notebooks

- `1_NumPy_Basics.ipynb`
- `1_Feature_Selection.ipynb`
- `1A_Logistic_Regression.ipynb`
- `1C_Logistic_Regression_using_Gradient_Descent.ipynb`
- `1D_Logistic_Regression_using_sklearn.ipynb`
- `02_Digital_Image_Representation.ipynb`
- `Mastering_Image_Processing_and_Computer_Vision.ipynb`
- `Python_Example_&_Documentation.ipynb`

## How to use

1. Open the notebooks in Jupyter Notebook or JupyterLab.
2. Install the required Python packages if needed.
3. Run the cells sequentially to follow the examples and exercises.

Typical dependencies may include:

- Python 3
- NumPy
- pandas
- scikit-learn
- matplotlib
- OpenCV
- Jupyter

## Getting started

```bash
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
pip install jupyter numpy pandas scikit-learn matplotlib opencv-python
jupyter notebook
```

## Repository purpose

This project is intended as a learning/resource repository for Python, machine learning, and image processing topics. It is suitable for students, self-learners, and anyone interested in practical notebook-based exercises.
